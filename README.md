# Automações AppScript — Ouvidoria

Este repositório reúne os arquivos da automação de Ouvidoria em Google Apps Script.
O fluxo preenche dados da planilha, resolve responsáveis e líderes, integra atividades
com o Pipedrive e envia notificações ao Discord conforme a origem e o setor da demanda.

A planilha operacional está disponível em:

[Planilha de Ouvidoria](https://docs.google.com/spreadsheets/d/1IIcwkhjbpuKWQ1xanIkB6DjTEcZB1K5P8DDXxzgUstA/edit?gid=1661377279#gid=1661377279)
